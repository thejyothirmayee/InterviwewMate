# InterviewMate - Feature Specification

## Core USP
InterviewMate is an adaptive placement journey for students/freshers.

## Flow
1. Create profile
2. Upload resume
3. Upload target job description
4. Extract skills
5. Calculate job match
6. Detect skill gaps
7. Take diagnostic
8. Generate roadmap
9. Practice each placement round
10. Run full placement simulation
11. Track performance
12. Get readiness recommendation

## Rounds
- Aptitude
- Coding
- Technical
- Project
- Managerial
- HR / Communication

## Future production upgrades
- LLM-powered semantic resume/JD analysis
- Voice interview with speech-to-text
- Speaking speed and filler-word analysis
- Real coding execution sandbox
- Company-specific current hiring patterns
- Resume rewriting for a selected JD
- Automated question generation from projects
- Calendar-based daily study plan
- Leaderboard / streaks
- Admin dashboard for colleges
